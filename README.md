# ИС учёта мероприятий · QazExpoCongress — прототип

Интерактивный прототип (без бэкенда) информационной системы учёта, планирования и
сопровождения мероприятий на объектах АО «НК «QazExpoCongress»: Конгресс-центр,
Международный выставочный центр, Международный центр искусственного интеллекта Alem.AI.

**Шаг 0 — дизайн-система.** Токены, библиотека компонентов и страница проверки
визуальной консистентности. Экраны (реестры, календарь, карточки, личный кабинет)
собираются на следующих шагах из готовых блоков.

## Демо

**https://morrison767.github.io/qazExpo/design-system**

Публикуется автоматически из ветки `main` через GitHub Actions
([.github/workflows/deploy.yml](.github/workflows/deploy.yml)). Сборка отдаётся из
подпути `/qazExpo/`; `404.html` дублирует `index.html`, чтобы работали прямые ссылки
на разделы.

## Дизайн-направление — «приборная панель»

Тёмный корпус несёт навигацию и сводку, светлые поверхности — рабочие данные.
Акцентный свет живёт только в тонких линиях, индикаторах и графиках: заливок им нет.

| Опора | Решение |
| --- | --- |
| Корпус | **Obsidian `#080D14`** — сайдбар, топбар, сводные полосы, шапки слайд-панелей; точечная сетка + радиальное свечение |
| Структура | **Ink Navy `#1B3A6B`** — primary-кнопки, таблички идентификаторов |
| Свет | **Beam Cyan `#35D6F0`** (на белом — `#0B7C93`) — активный пункт, фокус, индикаторы, графики |
| Сигнальный акцент | **Signal Amber `#D97706`** — «требует внимания», демо-метка |
| Нейтральная шкала | Холодный серый с синим подтоном (`ink`), фон приложения `#F5F6F8` |
| Шрифт | **IBM Plex Sans** (кириллица-native, табличные цифры), база 13px, приборные числа 44–72px; **IBM Plex Mono** — только идентификаторы |
| Подписная деталь | **Светящаяся кромка 3px** слева у всего, что имеет статус + **моно-табличка** с кодом объекта |
| Глубина | Три слоя: граница 1px + фаска-блик сверху + мягкая ambient-тень. Плоских прямоугольников нет |
| Движение | Каскад строк (шаг 14ms), досчёт чисел, пружина у панелей, shimmer-скелетоны; всё выключается `prefers-reduced-motion` |

### Контраст на корпусе

Все текстовые пары проверены расчётом: `obsidian-50` 16.7:1 · `obsidian-200` 7.9:1 ·
`obsidian-300` 4.9:1 (минимум для CAPS-меток) · `beam-300` 12.8:1 · `beam-700` на белом 4.9:1.
`obsidian-400` (3.7:1) используется только для иконок и декоративных элементов, не для текста.

### Палитра статусов — 8 токенов

`draft` · `review` · `confirmed` · `conflict` · `paid` · `unpaid` · `done` · `void`

Правило безусловное: **цвет никогда не единственный носитель смысла**. Каждый статус
несёт собственную иконку-форму и текстовую метку, а «Конфликт» дополнительно получает
диагональную штриховку. Раздел «Статусы» на `/design-system` содержит симуляцию
протанопии, дейтеранопии, тританопии и ч/б печати для проверки.

Контраст текста бейджа на подложке — не ниже 6:1 (WCAG AA/AAA), рассчитывается и
отображается на странице дизайн-системы.

## Правила работы с системой

1. **Hex не хардкодится в компонентах** — только Tailwind-классы из токенов либо импорт
   из `src/design/tokens.js`.
2. **Палитра статусов не переиспользуется** для справочных признаков (типы мероприятий,
   объекты, виды работ) — для них нейтральный `Badge`.
3. **Кромка обязательна**, если у объекта есть статус: карточка, строка реестра,
   элемент календаря, панель, тост.
4. **В табличке — только машинный идентификатор**: код зала, номер договора, БИН.
5. **Плотность по умолчанию** — строка 36px: реестр показывает 25 записей без прокрутки.
6. **Числа всегда табличные** (`tabular-nums`) и выравниваются вправо.
